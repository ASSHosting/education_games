# KI-Sicherheit

Lernspiele zu sicherem Umgang mit KI-Systemen, Prompting und Halluzinationserkennung.

## Struktur

- `b2b/` – vertiefte B2B-Varianten
  - `data-defender.html` – Datenschutz beim Prompten
  - `prompt-puzzler.html` – Prompt-Bausteine (Persona, Kontext, Ziel, Format)
  - `fake-or-fact.html` – Halluzinationen erkennen
  - `ki-oder-mensch.html` *(geplant)*
  - `prompt-builder.html` *(geplant)*
- `vhs/` – niedrigschwellige VHS-Varianten
  - `data-defender.html`
  - `fake-or-fact.html`

B2B und VHS decken teils dieselben Themen ab, sind aber didaktisch unterschiedlich (Tiefe, Szenarien, Zielgruppe).
